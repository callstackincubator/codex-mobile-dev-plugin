# Mobile Dev support

Mobile Dev is maintained by **Callstack**. Email
[hello@callstack.com](mailto:hello@callstack.com) for help, complaints, security
reports, or privacy requests.

## Bugs and setup questions

Use "Mobile Dev support" in the email subject, or open a
[GitHub issue](https://github.com/callstackincubator/mobile-dev/issues).
Include the plugin and host versions, macOS/device OS versions, the feature
involved, expected and actual behavior, and minimal reproduction steps.

Review any log or screenshot before sharing it. Do not include passwords, API
keys, device identifiers, customer data, or confidential project files. Public
GitHub issues are visible to others. The [README](README.md) lists supported
platforms and prerequisites.

## Security and privacy

Send security vulnerabilities privately by email with "Mobile Dev security" in
the subject. Describe the issue without posting an exploit or sensitive material
in a public issue; we can coordinate the necessary details by email.

For access, correction, deletion, or other privacy requests, use "Mobile Dev
privacy" in the subject. Read the [Privacy Policy](PRIVACY.md) for telemetry
opt-out and local-data controls. Do not send credentials to verify your identity.

The [Terms of Service](TERMS.md) identify the provider and describe complaints
and your rights. Support has no guaranteed response time unless separately
agreed or required by law.
