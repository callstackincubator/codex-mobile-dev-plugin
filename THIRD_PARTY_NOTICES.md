# Third-party code

The Android CPU and memory collector adapts [BAM Flashlight's native /proc collection approach](https://github.com/bamlab/flashlight/tree/5ef203ae184547a3b2984fa4f9b76d672895f861/packages/platforms/android/cpp-profiler) under the MIT License, copyright 2022 BAM. Its license, adapted C source and provenance ship in `dist/android-cpu`. `release.json` records the pinned upstream commit, compiler, source hash and hashes of the four bundled ABI binaries. This CPU and RSS memory adaptation excludes Flashlight's atrace and FPS collectors.

This plugin includes [Baguette 0.2.1](https://github.com/tddworks/baguette/tree/v0.2.1) by tddworks. Baguette uses the Apache License 2.0. Its full license sits at `dist/baguette/LICENSE`, beside its binary and full official resource bundle. We rebuild the unchanged v0.2.1 source with Swift 6.4 to avoid Swift task allocation crashes on macOS 27. `vendor/baguette-release.json` records the official archive URL, SHA-256, and source commit. `dist/baguette/release.json` also records the rebuilt binary SHA-256 and compiler version. `dist/baguette/third-party-licenses.txt` holds the Swift dependencies' licenses.

This plugin also includes [agent-device 0.20.9](https://github.com/callstack/agent-device/tree/v0.20.9) by Callstack under the MIT License. Its license sits at `dist/agent-device/node_modules/agent-device/LICENSE`. The package includes the official npm release, its Apple runner source, and all npm runtime dependencies with their licenses. `runtimes/agent-device/package-lock.json` pins each package and its integrity hash. `dist/agent-device/release.json` records the npm archive, integrity hash, and lockfile SHA-256. The bundled workflow guide comes from that CLI version's help.

The Baguette MCP server and panel bundle the Model Context Protocol SDK, MCP Apps SDK, OpenAI MCP Extensions, Zod, ws, React, Radix UI, Legend List, and their required JavaScript code. The panel uses shadcn/ui components under the MIT License and Tailwind CSS styles. It bundles Lucide icons under the ISC License, with Feather icons under the MIT License and Inter under the SIL Open Font License 1.1. `dist/third-party-licenses.txt` contains their licenses. The build preserves bundled license comments too.

This plugin includes [serve-emu 0.0.6](https://github.com/jiunshinn/serve-emu) by jiunshinn under the Apache License 2.0. Its package, dependencies, and licenses ship in `dist/serve-emu/node_modules`. `runtimes/serve-emu/package-lock.json` pins the npm packages and integrity hashes. `dist/serve-emu/release.json` records these hashes and the SHA-256 of the bundled [scrcpy 4.0 server](https://github.com/Genymobile/scrcpy/releases/tag/v4.0), also under the Apache License 2.0. The plugin uses serve-emu's CLI and HTTP/WebSocket APIs.

The Android fallback frame uses the nine-patch artwork and sizing approach from [mobile-next/react-device-view](https://github.com/mobile-next/react-device-view), under Apache License 2.0. The artwork derives from the Android SDK Pixel 9 frame. Attribution and license ship in `assets/android/nine-patch`.

The physical iOS capture addon uses [idevice](https://github.com/jkcoxson/idevice/tree/a64b8867815b3da17b5c927531bdba877e8456ef) (MIT) and media parsing/negotiation adapted from [device-hub-ios](https://github.com/JaviSoto/device-hub-ios/tree/1fcdfb0a6799b62f05625d0cbb359bec57256b94) (MIT). `dist/ios-mirror` includes both licenses and the native dependency license texts. `native/ios-mirror/Cargo.lock` pins its dependencies; `release.json` records the Node-API version, source hash, and binary hash.

The physical iOS unified-log reader uses [libimobiledevice 1.4.0](https://github.com/libimobiledevice/libimobiledevice/releases/tag/1.4.0), libusbmuxd 2.1.1, libimobiledevice-glue 1.3.2, libplist 2.8.0, and libtatsu 1.0.5 under LGPL 2.1 or later, plus OpenSSL 3.6.2 under Apache License 2.0. Its relay framing adapts libimobiledevice’s `src/ostrace.c`, copyright 2020–2025 Nikias Bassen. `dist/ios-logs` ships the collector source, replaceable dylibs, complete libimobiledevice dependency source archives, and license texts. `dependencies.json` pins source archive hashes, and `release.json` records source URLs, hashes, and bundled binary hashes. No Homebrew installation or runtime download is required.
